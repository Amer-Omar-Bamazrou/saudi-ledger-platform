## PART 2 — Fields to extract from every receipt/invoice
- Supplier/vendor name (as printed on the document)
- Supplier VAT registration number (15 digits, starts/ends with '3')
- Subtotal (before VAT)
- VAT amount
- Total amount
- Invoice/receipt date
- Invoice number if present

## PART 3 — Auto-create the supplier if it doesn't exist
- Look up the vendor by VAT registration number first (most reliable), 
  then fall back to fuzzy name matching if no clean VAT number was extracted.
- If no match is found, auto-create a new vendor from the extracted name 
  and VAT number, and flag it clearly on the review screen as "New 
  supplier — please confirm details" so the accountant knows it wasn't 
  an existing match.
- If a fuzzy name match exists but VAT numbers don't match exactly, show 
  both the extracted data and the closest existing vendor side by side 
  and let the accountant choose: link to existing, or create new anyway. 
  No silent auto-merging.

## PART 4 — Post-extraction review screen (before anything posts)
